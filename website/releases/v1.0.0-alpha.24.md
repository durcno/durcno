# durcno@1.0.0-alpha.24

## Minor Changes

- [052d138](https://github.com/durcno/durcno/commit/052d1388bc9f8d06409aba9bfcd5129e74607458) - Thanks to [@almahdi404](https://github.com/almahdi404) !

  > feat(columns): add real and double precision column types

  Added support for PostgreSQL `real` (single precision floating-point) and `double precision` column types in the query builder.

  - Includes schema generation and runtime validation logic for floating point values.
  - Ensures compatibility with mathematical functions (`abs`, `round`, `sum`) using type-safe abstractions.
  - Addresses a test syntax issue with exponentiation.

## Patch Changes

- [99beca8](https://github.com/durcno/durcno/commit/99beca85fa7b2951af58114f9572dd10b0db37f7) - Thanks to [@almahdi404](https://github.com/almahdi404) !

  > fix(query-builder): escape SQL identifiers and literals

  This update introduces `escIdentifier` and `escLiteral` helper functions to properly escape PostgreSQL identifiers and string literals. These functions are now utilized across the query builders (e.g. for column aliases, table aliases, and JSON keys) to neutralize potential SQL injection vulnerabilities.
