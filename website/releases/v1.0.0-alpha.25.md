# durcno@1.0.0-alpha.25

## Minor Changes

- [b71d48b](https://github.com/durcno/durcno/commit/b71d48b97011d07666275147dcb9cef35da22b85) - Thanks to [@almahdi404](https://github.com/almahdi404) !

  > feat(ddl): add extension and schema existence helper functions

  Introduces PostgreSQL extension DDL support (`CREATE EXTENSION` and `DROP EXTENSION`) to the migration DDL API, along with `IF NOT EXISTS` / `IF EXISTS` helper functions for schemas and extensions.

  The new helper functions include `createExtension`, `createExtensionIfNotExists`, `dropExtension`, `dropExtensionIfExists`, `createSchemaIfNotExists`, and `dropSchemaIfExists`.

  ```typescript
  ddl.createExtensionIfNotExists("vector").withSchema("public");
  // CREATE EXTENSION IF NOT EXISTS "vector" WITH SCHEMA "public";

  ddl.createSchemaIfNotExists("analytics");
  // CREATE SCHEMA IF NOT EXISTS analytics;
  ```

- [ac78909](https://github.com/durcno/durcno/commit/ac789096c3860c4d44cb0caa80bbd5115f602357) - Thanks to [@almahdi404](https://github.com/almahdi404) !

  > feat(functions): support literals and arguments

  Updated string and mathematical SQL functions to support literal values (e.g., strings, numbers) and `Arg` instances, expanding their flexibility beyond only accepting columns and other SQL functions.

  ```typescript
  import { lower, abs, Arg } from "durcno";

  // You can now pass literal values directly
  lower("HELLO"); // -> lower('HELLO')
  abs(-42); // -> abs(-42)

  // As well as Arg instances
  abs(Arg.number()); // -> abs($1)
  ```

- [d7cd66d](https://github.com/durcno/durcno/commit/d7cd66d4dafc8705af54ba894cb941e2a38fe102) - Thanks to [@almahdi404](https://github.com/almahdi404) !

  > feat(filters): add ilike string filter

  Introduces `ilike(col, pattern)` for case-insensitive pattern matching in WHERE and CHECK clauses, wrapping PostgreSQL's `ILIKE` operator.

  Supports both string literal patterns and query parameters via `Arg`.

  ```typescript
  import { ilike } from "durcno";

  await db.from(Users).select().where(ilike(Users.email, "%@example.com"));
  ```
