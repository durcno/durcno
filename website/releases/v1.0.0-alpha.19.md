# durcno@1.0.0-alpha.19

## Minor Changes

- [35393bb](https://github.com/durcno/durcno/commit/35393bb3b1cd6628b5a89df39092931bea9c8da3) - Thanks to [@almahdi404](https://github.com/almahdi404) !

  > feat(filters): support null and undefined in and/or combinators

  `and()` and `or()` now accept `null` and `undefined` as condition arguments and silently ignore them. This makes it straightforward to pass optional filters without needing to pre-filter the arguments array.

  ```typescript
  // Conditions can now be null/undefined without breaking the query
  const result = await db
    .from(Users)
    .select()
    .where(
      and(
        eq(Users.type, "admin"),
        someFlag ? eq(Users.status, "active") : undefined,
        otherFlag ? isNotNull(Users.email) : null,
      ),
    );
  ```

## Patch Changes

- [3b67bc8](https://github.com/durcno/durcno/commit/3b67bc80e5163cf73c1a2122fd0f9bb8a0b828e3) - Thanks to [@almahdi404](https://github.com/almahdi404) !

  > fix(cli): suppress cli log output

  CLI commands that apply or roll back migrations now disable the connector logger and use a single connection pool slot during their work. This prevents noisy SQL and transaction logs from leaking into normal command output while keeping the migration flow intact.
